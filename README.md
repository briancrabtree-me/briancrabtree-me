## /// What I do

I build and repair web systems where speed and clarity matter: semantic HTML, vanilla CSS, lean JavaScript, and deploy paths you can audit. Twenty-five years in production — from hand-coded HTML through React 19 SPAs. Performance is a product requirement, not a late pass.
